## Source-level causal defect isolated for V430
`Zero401LocalMotorCreditSafety.rearWallCanTeachMuscleV414` defines rear retreat using **positive signed displacement**, not a demonstrated positive velocity change. V429's `Zero420MotorMapEligibility.fromRealDecision` uses that same rear-only flag to allow exceptional wall trials into the upper `V371/V377` command→body response map. A body already sliding away from a wall can have positive displacement while slowing; this is **passive coasting**, not proof that its issued muscles produced the displacement. Such an episode can contaminate high-level steering evidence, even if the low-level V417 acceleration-based local gradient treats the episode differently. The V429 S21 count of 2,653 rear-wall eligible trials shows the hypothesis has substantial exposure, but it does NOT prove how many were passive; V430 adds an explicit counter.

## Exactly one V430 behavioral intervention
Only for the existing V420 high-level map laboratory opt-in, a rear-only wall trial is admitted into V371/V377 if its **measured POST-minus-PRE COM velocity projected onto the actual issued GRU3 heading is strictly positive**. If not, its high-level motor attribution is censored; normal clean no-wall trials still pass. This is a *necessary* measured acceleration sign, not a sufficient counterfactual demonstration: world drag may also produce acceleration. V414 lower-cortex training, actor/candidate distribution, V369 negative contact learning, GRU critic/reward, world, material solver, optical input, 194 senses, 512 weights and checkpoint serialization are untouched. Session-only `passiveRearRetreatRejectedV430` counter audits how often this exclusion actually occurs. Pure Android tests distinguish passive outward coasting, positive measured acceleration, lateral motion, nonfinite PRE and unchanged V377 bytes on rejected trial.
