Thus the motor cause from 10k unpaired actions remains unclear.

## Exactly one opt-in original behavioral intervention
**ZERO454 lab only**, activated via original `GameActivity.originalV454EnablePairedMotorContrastForQA()` after the original QA V400/V417/V421/V423 flags. The same 194-sensor / 64-GRU sole decision agent chooses all five existing motor intention fields as before. The same 512-coefficient 64-output cortex probes exactly ONE genuine CH0/CH1/CH3 actuator as V390. The original physics receives its real efference every substep, no extra force. Within one *self-issued* decision, the selected V390 physical muscle probe is alternated **ON, OFF, OFF, ON** across four consecutive true material substeps, continuing in disjoint 4-frame windows. OFF is the same learned cortical command without the exploratory perturbation; ON is the same cortex with its existing V390 sampled perturbation. The original normal baseline / all other motors / grip V319 continue as before.

`Zero454PairedMotorContrast` measures actual world post-step center-velocity changes relative to their immediately preceding physical frame, projected along that original GRU-selected unit heading. One complete physical quad reports `0.5*(Δv_ON0 - Δv_OFF1 - Δv_OFF2 + Δv_ON3)`. That ABBA contrast exactly rejects constant/linear passive acceleration **if locally linear**. It cannot prove a complete causal counterfactual under nonlinear material/body memory: this remains a **physical intervention estimate**, not a new physics model. A quad with any physically sensed solid contact, external correction or teleport is discarded; an incomplete quad is never counted. Require >=2 complete physically clean quads before the existing V401/414/432 harm/wall/contact gates can credit the current V390 probe. The local V332 motor synapse update reuses the existing V421 delivered-after-clipping probe and V423 single-own-decision training, replacing ONLY the old unpaired V417 total COM acceleration *credit target* with the scaled actual physical ON-minus-OFF contrast. **No changed neural choices, artificial resource labels or predictive collision coordinates.**

V454 changes a motor's exploratory ON/OFF schedule and the target for learning, so it must pass full real behavior tests. It does not alter the original brain/512 weights at restore or any serialized checkpoint structure; its flags/counters are transient and disabled for normal user.
