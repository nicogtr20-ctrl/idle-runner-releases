## Single V426 causal learning change
`Zero3RecurrentBrain.sample()` does **not** sample Gaussian sigma=0.20: it returns `0.20*(U1+...+U6-3)` with exact variance 0.02 (stddev 0.141421...), and compact Irwin–Hall support. The actor generates **3/5/7 independent option samples**; `Zero3CognitionV353.select`, planner and executive choose *after observing those samples*. The old selected-only `lastNoise/(.2*scale)^2` is therefore a conditional-selection-biased estimator; V425's selected-only tangent projection fixes an unexecuted radial derivative heuristic but is also **not** a valid score function for the actual sampled-set policy. Changing only the final selected sample's eligibility cannot prove actor learning is directed by true material outcome.

**V426 opt-in changes only the two high-level GRU heading actor weight gradients** to the bounded log-density score of the *entire actually sampled candidate set*, using the exact six-uniform distribution and each candidate's actual noise scale. The sampled heading/effort/grip/duration, chosen action, physical body, critic reward/advantage, 194 senses, GRU recurrence, V369 optical contact learning, V319 CH2, V424 local cortex credit and 512 weights are unchanged. For k>=3 when `embodiedImpass` replaces sampled heading with an independent uniform angle, the overwritten latent heading sample contributes **zero** to this estimator. Other 3 actor outputs retain prior rule. This is a likelihood-ratio estimator, not a claim of per-sample physical causality; radial noise can still add variance, so it may worsen movement. No synthetic reward, direction, new sensory channel or motor force.

V426 is activated only in original Android test paths after actual original GRU3 restoration and at a real decision boundary, with a new 5-case Android math/RNG/eligibility test. Existing V425 tangent flag may remain enabled for the comparator but the V426 heading estimator takes precedence when opt-in; the physical behavior difference is only the heading learning update. No V420/V422 flags are enabled.
