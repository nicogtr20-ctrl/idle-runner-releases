## Procedura pratica
1. Salvare ZERO attuale nello slot con nome sulla 0.11.4. Installare 0.11.6 direttamente tramite **AGGIORNA** oppure APK firmata verificata. **MAI disinstallare/azzerare** per aggiornare.
2. ANALISI → CONDIVIDI DATI CON GPT. Solo al primo invio, premere "APRI GITHUB PER CREARE IL TOKEN" e creare PAT fine-grained selezionando **solo il repository** e permesso **Contents Read and write**; salvare con dialogo app. Il token NON va incollato nella chat.
3. Premere/attendere **CONDIVIDI DATI CON GPT** → conferma "Report salvato su GitHub privato". Il tasto resta manuale ogni volta. Inviare in chat “Ho condiviso i dati di ZERO”.
4. ChatGPT: usare tool GitHub file privato a `ref=zero-telemetry`, `path=zero-telemetry/current.json`; ricavare dati reali, analizzare qualità apprendimenti e tendenze su vite, evitare di confondere i contatori con prove di intelligenza consapevole. Per comparare in tempo leggere `zero-telemetry/history/`.
5. Se il GitHub token di tipo fine-grained non ha Contents Write sul repository, upload non riesce; leggere errore e correggere l'autorizzazione. Non condividere mai il PAT con GPT o pubblicamente.
