# ZERO OTA169 — verified living motor skills, bounded archive and evidence-gated recall

Date 2026-10-16. Source branch `feature/zero169-verified-symbiote-motor-memory`. APK status must be independently confirmed by signed publisher + real public CDN bytes/SHA256 before user update.

## What's missing after OTA168
Cortex and proprioceptive somatic networks learn and save their **current** 84 + 320 + 320 weights, but unlike the legacy MotorSkillBank (used only by `!useSymbiote`) the symbiote has no saved *older, proven* joint motor configuration to fall back to when online plasticity degrades movement. Existing `TemporalSkillBank` stores high-level selected discrete actions 2–8 long, not membrane control and never substitutes a muscle configuration. Verified archival competence for real 64 actuators was therefore absent.

## Actual implementation
- `SymbioteMotorSkillMemoryV169`: snapshots **all 724 physically applied motor synapses**: 84 old shared cortex, 320 regional cortex, and 320 fast recurrent somatic weights. It does NOT snapshot or overwrite RecurrentCoreV22 or any brain neuron/decision/primary reward/sensor model.
- At the beginning of each ONE brain-chosen action, bank captures its complete muscle weights. Every real post-contact physics frame contributes legitimate center displacement and instantaneous actual membrane angular velocity. Frame-to-frame teleport/restart jumps >3 world units are explicitly rejected. Signed forward projection against brain's OWN direction, net/gross ratio, actual muscular metabolic cost and angular shear score each motor trial. Waving, rotation without forward progress, and pickup-event imagination cannot nominate a technique.
- A **training** decision with ≥4 physics frames, gross ≥2.8U, forward ≥1.8U, ratio ≥.38 and skill quality ≥.39 may nominate ONLY a candidate. Quality never directly trains the primary cortex.
- A candidate is never recoverable without at least TWO qualifying **heldout trials in distinct subsequent lives**, with actual motor weights similar (RMS <.036) to the *unchanged* nominated snapshot. Holding 100 frames or finishing multiple heldouts during the same life is not independent evidence.
- Maximum 4 verified archives + 6 tentative candidates, each tagged with the 2.2 action for which it worked. All archived versions preserve the **complete 724 weight snapshot** and real quality; no authored gait/template or synthetic reinforcement. Capacity+score constraints prevent global uncontrolled growth.
- **Recovery** is conservative: only if the brain independently selects **the identical 0..15 action** as a verified skill, there were 4 unsuccessful executed decisions for that action, a different current cortex weight set exists, and a 32-decision cooldown elapsed. Recovery installs only the saved three sets of bounded motor weights atomically; never changes 2.2 discrete action, heading, 40 neurons, neurogenesis, value, cortical training/heldout counters, sensor inputs, energy or world state. No recurrent motor phase preset; transient somatic activity/eligibility reset on retrieval to avoid applying stale muscle commands.
- An **optional new save key** `symbiote_motor_skills_v169` is used in real SharedPreferences and all twelve named save profiles. Old slots without memory load normally with EMPTY skill bank. `ms169` validation is fail-closed and atomic: unsupported length, nonfinite weights, invalid action, forged life/heldout provenance, bad counters and truncated records are rejected without destroying existing archive. Selective MEMBRANE domain reset now appropriately clears V167 fast and V169 motor bank together. Old keys `smh1`,`cl161`,`sf167`,`co162`,`md165`,`rc22` unchanged.
- Brain/Body/Skills read-only UI shows real verified bank, pending candidate count, independent heldout count, and recovery activations; prominent zero means **no confirmed motor skill yet**, not lost brain.
