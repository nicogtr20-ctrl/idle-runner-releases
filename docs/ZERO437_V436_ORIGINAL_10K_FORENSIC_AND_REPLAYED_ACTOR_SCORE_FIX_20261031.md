## V437 — ONE source-confirmed causal actor-gradient defect
In original `Zero3RecurrentBrain.choose` the first candidate's heading noise is **`noise[0][j]=lastNoise[j]`**, reused from the **previous completed decision** to provide continuity. Fresh stochastic draws occur only for `k>=1`. But the opt-in V426 `Zero426JointSampleActorScore.headingScore` incorrectly sums the score-function gradients from **all k including 0**. Candidate 0's previous-decision random noise is not a random variable sampled from the **current decision's** actor policy. Worse, its previous scale can differ from current scale=1; an old wide 2.5x heading can saturate the V426 score and inject wrong-sign current actor credit. This is a direct causal estimator bug, independently of any claim that it alone explains the body's inertia.

**Single behavioral change**: sum V426 heading score over `k=1..n-1` only. Keep candidate 0 in actual choice set unchanged, all fresh candidate draws unchanged, all optical scoring unchanged, real rewards/critic/GRU weights update machinery unchanged. No fixed heading, auto-brake, innate red class, V2.2, body/physics change, altered 194 sensors, V319 CH2, 512 synapses, V356 serialization or 12 saved slots. V426 score flag is already enabled in the experimental original V436 S21/wild harness, so this one-line estimator repair is exercised in actual Android behavior.

Android regression expands `Zero426JointSampleActorScoreAndroidTest` from 5 to 8 cases: original latent density, fresh-only candidate set, replayed candidate 0 cannot affect current score, seven-choice six fresh draws, single replay-only option gives zero current heading gradient, independent uniform impasse exclusion, unchanged first GRU choice and RNG.
