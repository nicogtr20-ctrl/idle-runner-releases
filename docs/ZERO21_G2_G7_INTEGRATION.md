## Purpose and status
This intervention is deliberately ONE project, not separate unrelated cognitive bonuses. The existing original Zero brain retains control of the 16 actions. The ZERO21 modules together connect:
(1) self/scene sensing → (2) provisional multi-view anonymous object tracks → (3) chosen action + real physics witness → (4) mechanical competence archive, real contact energy and delayed link *hypotheses* → (5) calibrated shared evidence → (6) conservative homeostatic/risk decision shadow proposal. None of them get a special 'box', 'energy hidden behind it', 'go here' or 'open gate' signal, and no new reward is given for mere physical movement. This phase adds **research code and strict tests**, not an actuating replacement brain.

## G2 — observed geometry → tentative multi-view instance hypotheses
**Class:** `ObjectContinuityV21.java`. `SensorimotorMind.observe` supplies only `SpatialPerception.ranges()` (sixteen first-return, occluded depth rays), self-observed `perceivedX()/perceivedY()` odometry, ordinary sensed fraction of touched tissue `after[4]`, and the existing holdout training flag. The class never imports a game entity or simulator hidden coordinate.

Anonymous sight clusters are contiguous arc runs of 1–5 hit rays, with proper angular wrap. Full rings and excessively broad wall-like clusters are not declared isolated objects. Their approximate position is inferred by ray angle plus measured distance and self-odometry; tracker correspondence uses conservative world-relative separation, shape arc span, distance mismatch and competing hypotheses. A closely competing assignment abstains rather than forcibly merging independent objects. Stable object track only after repeated observations; ambiguous multipoint scenes yield no unique focus. Max 12 life-local tracks; stale hypotheses expire after eight views. The working model understands this as **noisy 2D relative sightings**, not definite rectangle/circle classification, true 3D, or privileged physical instance identity.

**Important geometric limitation:** in the actual Galaxy S21 simulation the 16 sensors originate from different physical membrane patches, not from the mass centroid. The ray sweep currently exposes normalized lengths but not all membrane-eye offsets through `ranges()`. Estimated track position therefore contains body-shape-dependent registration error. This is an EXPLICIT blocker to claiming reliable object identity or causal object motion. Next experiment must extend the ordinary sensor interface with measured ray origin offsets to improve localization, not read the engine's actual object center. Ground truth object IDs can be used ONLY in a separately partitioned evaluator to measure identity-switch rate. Validate near adjacent boxes, wall, rotating plate, partial occlusion, crossing tracks and severe body deformation before advisory.

**Durable state:** `object_continuity_v21` format `oc21` holds only bounded aggregate learning and evidence counters, NOT track ID or positions. Reincarnation or resumed app does not hallucinate continuous tracking of yesterday's object. Spatial selective reset includes the new key. Old slots without the key migrate safely with virgin ZERO21 tracking and preserved learned old model weights. Atomic parse rejects nonfinite, truncated and incompatible payloads.

## G4 — time-aligned movement vs energy is NOT demonstrated causality
Only after a freely chosen actual action and two rays scans of a repeatedly observed anonymous focus near physically sensed touch does the tracker evaluate a possible scene-level movement. It checks BOTH new observed geometry and the separate original measured external physical change. Big uncorrespondable jumps cannot be assigned to the same object. If energy is physically collected within eight later decisions after a single tracked movement candidate, record **possible delayed temporal association**. Multiple plausible moved tracks make the energy link ambiguous. If there is no credible recent movement, label energy unlinked. A record does not prove that an action on the focused object caused energy to appear. Contact reward is never fabricated from moving tissue, movement alone, global on/off adhesion, a skill suggestion, or a planner forecast.

Train vs holdout: the original `LearningDiagnostics.shouldHoldout()` split is reused without drawing a new sample. Both the unified shared ledger and object continuity only train outcome/action cells on actual training intervals. Heldout labels contribute to validation error against a no-change predictor; no prototype/knowledge counters are incremented from heldout decisions. Diagnostic global raw contact and ambiguity counters can be reported separately even on heldout, but **do not use them to select action values**. The planned extension is a causal hypothesis register with independent base-rate controls and well-calibrated change-point detection, not a shortcut that assumes every moved object contains food.

## G3 / G5 — durable actual HAND+MEMBRANE skill evidence
**Class:** `CompetenceMemoryV21.java`. Real `GameActivity` witnesses applied 18 HAND + 82 MEMBRANE coefficients when the *existing physical cover collision solver* has confirmed simultaneous opposing adhesion AND observed real external displacement >0.005 units. Sensory context comes from the old 26 self/visual channels; anonymous-tracker confidence is preserved only as an **uncertainty annotation**, not as a proven object ID. Candidate weight snapshots are bounded at 8 techniques, and similar pairs in similar perceived contexts aggregate repeated actual frames. At least 6 real-motion frames and two **distinct physical lives** are required before the evaluation-only `candidate` method offers a read-only technique snapshot. The class **cannot apply it to motors**. The trusted existing `GripSkillBank` retains full and exclusive control of current phone hand/membrane rollback logic. This intentionally avoids introducing motor regression and requires future heldout replay of candidate techniques before allowing new autonomous skill recovery.

A life is incremented only when `lifeStats.death()` really closes, not when Android restarts, slot switches or simulated time is accelerated. A contact without an actual opposed hold or displacement never creates a technique. Neither a new object category nor free energy is added. Persisted key `competence_memory_v21`, format `cm21`, placed under the MEMBRANE reset domain with no overlap. Corrupt or missing saves are handled atomically with older slots unaffected. A technique's competence (can it actually move) and instrumental benefit (is it useful here) remain intentionally separated.

**Remaining gap:** currently archival eligibility uses existing cover physical solver's witness on the integration side. That does not imply the learner independently inferred the same bilateral condition; before using archives to steer action, the sensory model must show reliable recognition of opposing self tissue contacts and independently tracked obstacle displacement, validated against physical engine ground truth used only by evaluator. Until then, the new archive is an evidence bank, not a learned generalized affordance controller.

## G6 — one cautious shared homeostatic proposal, never an action
**Class:** `UnifiedArbiterV21.java`. The original `UnifiedCognitionV21` now exposes read-only empirical samples, contact energy mean, physically observed effect probability and negative event frequency per actual 26-input coarse context × chosen action. Evaluation occurs *after* the original normal policy selected its motor action (only each eighth decision), and after the old `FuturePlannerV20` shadow research pass. It requires:
- Existing world predictor out-of-training improvement over unchanged-state baseline, >0.10 confidence and valid errors;
- Shared action/effect ledger independent heldout improvement, >0.10 confidence;
- At least 12 genuine training opportunities for every alternative considered;
- Strong distinct ranking and agreement with separately validated future-plan suggestion;
- No trust in unresolved near-contact object hypotheses.

Utility combines truly **experienced contact energy**, learned harmful contact rate, physiological reserve-driven urgency, a strictly small mechanical capability bonus only near sensed solids with adequate energy, and an evidence-count uncertainty penalty. There is no hardcoded 'blue', cassa, opening direction, or known world frequency, no access to fixed object probabilities and **NO ACTUATING API OR CHOICE SCORE TERM**. With the current poor world-predictor calibration the correct result is usually **abstention**; that is a safety property, not intelligence uplift.

Persistence `unified_arbiter_v21` format `ua21` holds metrics only, not imagined action or executable plan. WORLD selective reset erases them; new life clears proposed action, not aggregate tests. Independent zero21 regression asserts 400 abstentions on virgin evidence and atomic persistence.

## What still blocks a genuine smarter ZERO and release
1. Reliable membrane-mounted ray-origin calibration and persistent single-instance identity under occlusion / body deformation; no hidden IDs to learner.
2. Genuine causal credit when manipulated obstacle and eventual food contact are far apart in time; counterfactual/base rate controls.
3. Proof of durable skill retrieval after mutant weights drift, not only witness archive (matched heldout physics and repeated lives).
4. A decision arbiter allowed to influence actions ONLY after world/energy confidence and unseen-world effectiveness are measured; current confidence normally 0.
5. Long-life, multiple-distribution, heldout A/B with nonzero gains and preservation of proven motor/physical skills; special focus on scarce reward, novel shapes, change points.
6. Full S21 profiling of x20 CPU/RAM/battery/thermal and user save/slot migration in-place. CI green cannot certify the real device.
7. Official Android signed release via preexisting `feature/overmind-inapp-updater` publisher ONLY after criteria hold. Do not modify `main/updater/public/latest.json` or Vercel or claim `AGGIORNA` currently has ZERO21.
