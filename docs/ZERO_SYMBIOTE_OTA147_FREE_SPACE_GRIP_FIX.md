## Confirmed OTA146 code bug, distinct from inadequate brain experience
The OTA146 physics patch had set `float traction=clip(.50f+2.75f*cortex[sector*OUTPUTS+2],0f,1f)` then `drag=exp(-(1.8f+66f*traction)*dt)`. Even at zero active grip, the 0.5 passive traction produces an instantaneous damping coefficient 34.8 / simulated second; at `dt=.025`, speed is multiplied by ~0.419 **every frame**, losing ~58% per frame. More seriously, `SymbioteMotorHeadV1` quite deliberately maps primary 2.2 actions 8..15 to voluntary obstacle-gripping commands in all 16 sectors, so `traction` saturates ~1 and immobilizes membrane even when there is **NO contacted obstacle**. This mixes obstacle adhesion (requires physical collision) with ubiquitous floor support (normal pressure/friction), an error introduced by OTA146. It can make initial transient shape relaxation after birth appear as the last visible activity, with no effective locomotion. No brain-prediction or reward change would solve it.

## Corrected physical design
- In `SymbioteMatterV1.java`, keep the existing object-grip command `skin.gripCommand[i]=adhesive` for REAL physically contacting box/gate. The floor drag must **not** depend on `adhesive` or on action-bank grip bit. Use a modest passive floor support plus local **compressive** active cortex loading: `compression=max(0,-extend)`, `traction=clip(.12+1.45*compression,0,.95)`, `drag=exp(-(1.8+66*traction)*dt)`. This lets extending patches slide while contracting patches can provide local ground reaction, but without a prescribed traveling wave, fake force on the center, resource location, or locomotion reward. The passive .12 level is needed for independent pseudopod formation with physically exchanged momentum.
- Preserve `SymbioteMotorHeadV1`, existing neuron brain 2.2, exploration and reward; no learning weights or game save schema changes. New body remains soft, 96 perimeter + 74 viscous internal material points, no ghost anchor.
- Extend `SymbioteMatterV1Regression.java` with a noncontact matched A/B: two bodies receive identical pressure/shear/stiffness muscle commands but one also commands 0.9 voluntary object grip **in free space**. Physics paths must remain identical (this test would fail on OTA146). Another fixture keeps a completely passive body alive for >41 simulated seconds, then applies new externally specified local muscle actuation and requires pseudopod response, no self-crossing or invalid particles. These are **physical actuator acceptance tests, not gameplay commands**.
- A first proposed zero-floor-friction implementation FAILED the pre-release test `no independent pseudopod exists` on run [38654330994](https://github.com/nicogtr20-ctrl/idle-runner-releases/actions/runs/38654330994).
