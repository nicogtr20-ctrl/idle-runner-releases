## Genuine 2.2 growth (not a UI counter)
- The 2.2 starts with **24 recurrent units** and may gain up to **16 additional units (40 total)**, in bounded steps.
- Each `NeurogenesisV22.Node` is a real nonlinear recurrent unit with 16 trainable incoming sensory+old-core connections, self-recurrence, bias, and 16 outgoing connections feeding the SAME live 2.2 primary choice scores. Acceptance changes the physically executed decision policy. It does **not** create a new planner, actor, fake direct energy, target heading, or motor-controller.
- Candidates created only after enough physically executed training transitions, trained only on training-only reward prediction residuals and assessed against incumbent reward prediction on **32+ independent heldout** transitions; accept only for >8% baseline MSE improvement with minimum baseline residual, otherwise reject by 64 heldout transitions. Limited influence by independent heldout gain and a strict overall [-0.15,0.15] action-score cap. No free neurons on elapsed time, number of lives, noise alone, or holding buttons.
- Maximum 16 grown units constrains memory/CPU on Galaxy S21. Growth events and rejected proposals are captured in saved state. Fixed original trained F164/H24 nucleus and 84-weight physical cortex are preserved intact.
- The `rc22` encode/restore retains the existing compressed CRC-checked immutable model snapshot and adds a bounded, checked optional neurogenesis trailer. Existing OTA158 `rc22` without trailer restores as **24 real neurons**, preserving trained original coefficients. Invalid/truncated expanded payload **never partially overwrites** the healthy saved brain.
- `BrainStatsActivity` native animated 3D network now paints **exactly** `RecurrentCoreV22.totalNeurons()` points; first 24 teal, newly accepted recurrent units violet. Stronger actual recurrent links of added units are drawn according to the new trained synaptic data. Central text and Evoluzione/Cervello/Parametri show original, added, attempts, rejects, last validated gain and additional learned synapse count. The image is a projection, not a second neural system.
- No changes to 2.2 base reward, body forces, physical muscle head, collision solver, telemetry secrets, Android package or signature. Existing in-game "AGGIORNA" used to install OTA.
