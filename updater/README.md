# OVERMIND ZERO updater hosting (Vercel)

This folder is a static public Vercel root. Configure Vercel project root directory `updater` and output directory `public`.

`/latest.json` is a **disabled placeholder** until a stable signing pipeline and a real APK distribution path exist. Never enable `available` before publishing the exact APK and computing its SHA-256.

See `../docs/UPDATES.md` for the protocol, prerequisites, security limitations and end-to-end testing steps.
